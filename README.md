## 📸 Cómo agregar fotos a la Galería (sin tocar código)

La sección **Galería Jaguar** se llena sola con las fotos de la carpeta
[`assets/galeria/`](assets/galeria/). Para agregar fotos:

1. Entra a la carpeta `assets/galeria/` en GitHub (desde una computadora)
2. Clic en **Add file → Upload files**
3. Arrastra las fotos (JPG, PNG o WebP)
4. Clic en el botón verde **Commit changes**

En 1-2 minutos la página se actualiza sola con las fotos nuevas. Para quitar
una foto, bórrala de esa carpeta.

💡 **Consejo:** nombra los archivos con palabras descriptivas separadas por
guiones (ej. `campeonas-2026.jpg`), porque el nombre se usa como descripción
de la foto.
